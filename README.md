# The Wedding Plan

The command center for 7 · 7 · 27.

## Pages

**`index.html`** · The Plans tracker (the homepage). Kanban of live work in three columns: Discover · Decide · Execute. Loads `sidebar.js`, `api.js`, `tracker.js`.

**`brief/`**
- The Brief: `the-look.html`, `the-flora.html`, `the-dress.html`
- The Plans: `the-journey.html`, `the-logistics.html`

**`dashboard/`**
- The Plans: `day-of.html` (The Day)

## Assets

- `css/base.css` · palette, typography, resets; design tokens at the top
- `css/site.css` · layout, sidebar, thread style, tracker
- `css/dress.css` · The Dress page
- `js/sidebar.js` · sidebar on every page: nav, countdown (to the 2:00 PM start), RSVP bar
- `js/api.js` · fetch wrapper for the live Apps Script API
- `js/tracker.js` · the homepage board
- `js/main.js` · shared helpers for the brief and dashboard pages
- `img/flora/`, `img/dress/refs-v3/`, `img/mood/`
